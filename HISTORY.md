# History

Personal site for [matthewlsawyer.com](https://matthewlsawyer.com) — an 11ty static site on GitHub Pages with Tailwind, a portrait-led identity homepage, and a posts collection for writing about Throneroom and the Grimoire spellbook. This ledger records how the site evolved from a January 2025 placeholder through a July 2026 reboot into a publishing surface for agent-skills work.

## Story

A long-dormant GitHub Pages repo rebooted in July 2026 as a Liquid-based identity page and posts hub, then became the public home for Throneroom thinking and the three Grimoire spells.

### Origins

Initial commit January 23, 2025 (`9bf1e36`) with a single `index.html`. Same week: 11ty scaffold (`370f4d5`), README (`ef0a3e0`), and CNAME for matthewlsawyer.com (`39accac`). February brought Tailwind, GitHub Actions, responsive layouts, and typography polish (`dd84f01` through `eb06645`) — then the repo went quiet for over a year.
